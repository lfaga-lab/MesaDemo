# Portada estándar para demos NUVORA

Todas las demos comerciales de NUVORA deben comenzar con la misma arquitectura visual y narrativa.

## Estructura obligatoria

### Panel izquierdo

1. Identificación `NUVORA · DIGITAL PRODUCTS LAB`.
2. Etiqueta `NUVORA LAB · FEATURED`.
3. Nombre del producto en gran escala y dividido en dos bloques.
4. Promesa principal del producto en una sola oración.
5. Etiqueta `DEMO COMERCIAL`.
6. Aclaración de datos ficticios.
7. Versión y año.
8. Inicial del producto como marca de agua.

### Panel derecho

1. Kicker `EXPLORAR [PRODUCTO]`.
2. Título adaptado a la cantidad de perfiles disponibles.
3. Explicación breve del propósito de la demo.
4. Un acceso por cada rol o experiencia relevante.
5. Aclaración final sobre el entorno de demostración.

## Regla de perfiles

La portada no debe imponer siempre dos recorridos. Debe mostrar todos los lados necesarios para comprender el producto.

Ejemplos:

- MENTA: Profesional / Paciente.
- MESA: Salón / Cocina / Caja.
- Escuela: Dirección / Docente / Familia.
- Tienda: Administración / Vendedor / Cliente.

## Comportamiento

- Cada opción abre directamente la vista correspondiente.
- Siempre debe existir una acción `Volver al inicio`.
- Al actualizar la página debe volver a mostrarse la portada.
- La portada debe adaptarse a computadora y celular.
- No debe contener referencias a herramientas utilizadas para desarrollarla.

## Elementos variables

- nombre del producto;
- color de acento;
- promesa;
- perfiles disponibles;
- descripciones de cada perfil;
- inicial utilizada como marca de agua.

La estructura, jerarquía, espaciado, tono y firma NUVORA deben mantenerse constantes.
