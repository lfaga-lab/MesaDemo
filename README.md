# MESA · Demo comercial

Demo web de **NUVORA Lab · Gastronomía**, preparada para publicarse directamente con GitHub Pages.

## Qué incluye

- panel general del servicio;
- mapa y estados de mesas;
- carga de comandas;
- carta por categorías;
- envío de pedidos a Cocina;
- Kitchen Display System;
- estados Nuevo, En preparación, Listo y Entregado;
- seguimiento de comandas;
- caja y métricas;
- recorrido guiado;
- diseño responsive;
- datos ficticios restaurables.

## Publicación

No requiere instalación ni compilación. Subí todos los archivos a un repositorio y activá GitHub Pages desde `Settings > Pages`.

Las instrucciones completas están en `LEEME_PARA_SUBIR.txt`.

## Sincronización de la demostración

La versión inicial funciona localmente y sincroniza automáticamente las pestañas abiertas en el mismo navegador. `config.js` deja preparada la incorporación posterior de una API remota sin modificar la interfaz.

## Archivos

- `index.html`: estructura de la aplicación.
- `styles.css`: identidad visual y adaptación móvil.
- `app.js`: datos ficticios y funcionamiento.
- `config.js`: configuración pública.
- `assets/`: recursos gráficos.

Todos los nombres, reservas, comandas y métricas son ficticios.
